# Changelog

All notable changes to ViperX will be documented in this file.

## [5.0.0] - 2026-08-01

### This version added NBTAPI as a dependency

- Added more documentation to the config
- Switch to NBTAPI
- Added the ability to remove NBT tags from the player NBT which also works for any custom NBT tag
- Restricted access to the main ViperX menu so operator-only actions remain protected.
- Allowed non-operators to access the public `viperx.links` menu through `/viperx`.
- Kept `viperx.links` available to all players while the rest of the ViperX menus remain operator-only.

### Notes
- `/viperx` and `/vx` now open the main menu for operators and the links menu for everyone else.
- The command flow was updated to match the intended public/private menu split.


## [4.1.0] - 2025-10-06

### Changed
- Restricted access to the main ViperX menu so operator-only actions remain protected.
